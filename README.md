# TO-DO
To Do Flow is a modern, feature-rich Todo app built with React, Redux, and Tailwind CSS. It is designed with a clean UI and corporate-friendly features to help professionals manage their daily tasks with clarity and ease.
🚀 Features

✅ Add, Edit, Complete & Delete tasks

📊 Progress Overview – Track total, active, and completed tasks

🔍 Filter by All / Active / Completed

🎨 Clean UI – Tailwind CSS powered sleek and responsive design

⚡ Smooth animations for interactions and transitions

🧠 Built with Redux Toolkit for scalable state management
